
消費期限管理アプリ (Expiry Manager)

家庭や飲食店・店舗等における食品や消耗品の「消費期限・賞味期限」を一元管理し、期限切れによる廃棄ロス（フードロス）を未然に防ぐWebアプリケーションです。

・ 開発の背景と目的

家で料理をする際、たまにしか使わない調味料や食材などの「消費期限がいつだったか分からない」と困ることがよくありました。
この身近な悩みを解決するテーマがWebアプリ開発の題材として最適だと感じ、本アプリの開発に至りました。

「手軽に登録でき、期限が近いものをひと目で確認できる仕組み」を作ることで、食材の無駄をなくし、効率的な在庫管理を目指しています


・ 主な機能

- **ユーザー認証・認可機能**
  - Spring Securityを用いた安全なログイン・ログアウト
  - ログインユーザーごとの個別データ管理
- **品目・消費期限データ管理（CRUD機能）**
  - 品目（食品名など）、カテゴリ、消費期限、価格の登録・編集・削除・一覧表示
- **ステータス別アラート・視覚化機能**
  - 期限までの日数に応じた判定表示（Bootstrap 5によるバッジ・アラート表示）
    - 🟢 **安全**: 期限まで余裕あり
    - 🟡 **注意**: 期限間近（例: 3日以内）
    - 🔴 **警告**: 期限切れ
- **検索・絞り込み機能**
  - 品名やカテゴリによるスムーズな検索

・ こだわり・工夫した点

 1. 現場での利便性と快適性を追求したUI/UX
* **直感的な期限ステータス表示**
  * 校正期限の当日までは「使用可能（期限間近）」とし、翌日以降（昨日以前）を「期限切れ」とする現場の運用に即した判定ルールを採用。ユーザーがひと目で優先対応すべき機器を判断できるようにしています。
* **快適なダークモード対応（CSS変数の活用）**
  * CSS変数（`--bg-default`, `--text-main` 等）を用いたテーマ設計を行い、入力フォーム（`input`, `select`）やテーブル内の視認性を確保。作業環境やユーザーの好みに応じて文字が見づらくならないよう、色のコントラストに徹底配慮しました。
* **ユーザーフレンドリーなフィードバック**
  * 新規会員登録成功時に `redirect:/login?register_success` を付与し、ログイン画面側で「登録完了」メッセージを表示。エラー発生時も入力画面へ安全に押し戻してエラー内容を提示するなど、迷わせない導線設計を行いました。

 2. 堅牢なセキュリティと多層防御（マルチテナント・IDOR対策）
* **徹底した所有者チェック**
  * 他人のデータIDを直叩き（URL直接入力等）してアクセス・編集・削除を試みる悪意あるリクエストを未然に防ぐため、Service層のすべての操作（`updateItem`, `deleteItem`, `toggleUsedStatus`）で「データベース上の所有者ユーザー名」と「ログインユーザー名」の厳格な照合を実施しています。
* **データ漏洩を防ぐ暗号化**
  * Spring Security および `BCryptPasswordEncoder` を採用し、ユーザーのパスワードはハッシュ化してDBへ保存。万が一のDB漏洩時にも生のパスワードが流出しない設計としています。
* **権限に応じた適切なアクセス制御**
  * `SecurityConfig` にて未ログインユーザーがアクセスできる範囲（`/login`, `/register`, `/css/**`）と、認証が必須なエリア（`/items` 等）を明確に分離しています。
